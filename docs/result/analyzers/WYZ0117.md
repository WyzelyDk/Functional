# WYZ0117: Use Flatten instead of a Bind that returns the nested result

| | |
|---|---|
| Category | Design |
| Default severity | Info (a suggestion; it never breaks a build) |

## Cause

A `Bind` on a result of a result whose delegate returns its parameter:

```csharp
Result<Result<Order>> nested = Load(id).Map(Validate);
return nested.Bind(inner => inner);
```

## Why it matters

`Flatten` is that operation, and its name says what happens to the two levels.

## How to fix

```csharp
return nested.Flatten();
```

## What is left alone

A delegate that does anything else, an `async` delegate, and a `Bind` on a result that is not nested.

## Code fix

Yes. The fix renames the call and removes the delegate, and works with "fix all".

## When to change the severity

The rule is a suggestion, so it shows up in the editor and not in the build output. Make it louder, or switch it off, in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.WYZ0117.severity = warning   # or none
```
