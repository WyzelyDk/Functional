# WYZ0202: Use Any instead of Filter followed by IsSome

| | |
|---|---|
| Category | Design |
| Default severity | Info (a suggestion; it never breaks a build) |

## Cause

`Filter` on a `Maybe<T>`, and then `IsSome` on the result:

```csharp
var hasLargeOrder = order.Filter(o => o.Total > 1000m).IsSome;
```

## Why it matters

The question is whether there is a value that satisfies a condition, and `Any` asks it. `Filter` builds a maybe only to ask whether it has a value.

## How to fix

```csharp
var hasLargeOrder = order.Any(o => o.Total > 1000m);
```

## What is left alone

`Filter(...).IsNone`, which is not `Any`, a `Filter` whose result is used as a maybe, and a `Filter` that is not written as `receiver.Filter(...)`.

## Code fix

Yes. The fix renames the `Filter` call to `Any` and drops `.IsSome`, and works with "fix all".

## When to change the severity

The rule is a suggestion, so it shows up in the editor and not in the build output. Make it louder, or switch it off, in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.WYZ0202.severity = warning   # or none
```
