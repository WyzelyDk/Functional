# Code of Conduct

This project has adopted the code of conduct defined by the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
to clarify expected behavior in our community.

It applies in all project spaces: the issues, pull requests and discussions of this repository, and any place where someone represents the
project.

## Reporting

Report unacceptable behavior to a maintainer via the contact methods listed on the GitHub profile.
